# ПАЗЛ 2007

Браузерная игра-пазл по одиннадцати кадрам зимы 2007 года.

Каждый кадр — реальное фото, рассыпавшееся на кусочки пазла. Игрок таскает
кусочки по столу, они «щёлкают» на свои места, и как только кадр собран —
он превращается в свою аниме-версию: сначала волной по кусочкам на доске,
а потом ползунком «фото / аниме» в окне победы.

Оформление — окно в духе интерфейсов 2007 года, со звуками, галереей
собранных кадров и сохранением прогресса в браузере.

## Запуск

Игра статичная, но использует ES-модули, поэтому нужен локальный сервер
(по `file://` браузер заблокирует импорты):

```bash
python3 -m http.server 8080     # или: npm start
```

и открыть <http://localhost:8080>.

На хостинге достаточно скопировать репозиторий как есть — например,
включить GitHub Pages на ветке с игрой. Сборка не требуется.

## Как играть

* Тащи кусочек мышью или пальцем. Рядом со своим местом он щёлкнет и встанет сам.
* Уровни открываются по очереди: следующий кадр доступен после сборки предыдущего.
* Собрав кадр целиком, увидишь его аниме-версию и ползунок «фото / аниме».
* Кнопки уровня: **Перемешать**, **Подсказка** (силуэт кадра, 3 штуки на кадр),
  **Показать кадр** (подсмотреть результат), **Заново**.
* Клавиши: `Esc` — к уровням, `Пробел` — перемешать, `H` — подсказка, `R` — заново,
  `P` — показать кадр.
* Прогресс и лучшие времена хранятся в `localStorage`.

## Структура

```
index.html            разметка игры
css/app.css           оформление (тёмный стол + окно в стиле 2007)
js/app.js             экраны, перетаскивание, победа, галерея, звук
js/jigsaw.js          геометрия джигсав-кусочков (SVG-пути, замки)
js/game-core.js       правила уровня: положение кусочков, щелчок на место
js/layout.js          раскладка стола: где доска и где кусочки
js/levels.js          список кадров и пути к ассетам
js/audio.js           синтезированные звуки (WebAudio, без файлов)
js/storage.js         сохранение прогресса в localStorage
real/, anime/         исходные кадры
assets/opt/           оптимизированные копии для игры (собираются скриптом)
tools/                скрипты сборки и проверок
```

## Инструменты

```bash
npm run assets           # пересобрать assets/opt из real/ и anime/
npm run check:geometry   # нарезка фото по контурам — видно, стыкуются ли замки
npm run check:layout     # ASCII-карта раскладки для 12 размеров окна
npm test                 # прогон игры в jsdom (npm i --no-save jsdom)
node tools/preview-compose.mjs 11 1440 900   # картинка-превью стола
```

Проверки пишут результаты в `checks/` и `preview/` — это отладочные
артефакты, в репозиторий они не попадают.

## Как добавить свой кадр

1. Положить фото в `real/NN.jpg` и его аниме-версию в `anime/NN.png` (те же
   пропорции — 1080×1349 или близкие).
2. `npm run assets` — появятся оптимизированные копии в `assets/opt/`.
3. Добавить уровень в `LEVELS` в `js/levels.js`: `id`, название, `cols` × `rows`
   и `seed` (фиксирует разводку замков).

## Технические заметки

* Кусочки — не картинки-куски, а одна и та же фотография, обрезанная
  SVG `clipPath` в форме кусочка (`preserveAspectRatio="none"` растягивает
  кадр ровно на доску). Поэтому canvas не нужен: нет ни tainting CORS,
  ни пиксельных операций, а игра работает и с локального сервера, и с диска
  через простой http-сервер, и на мобильных.
* Замки строятся по сетке `cols × rows`: общий «шов» между соседями считается
  один раз, поэтому кусочки стыкуются идеально. Формулы проверены оффлайн-
  рендером (`npm run check:geometry`).
* Финал уровня: доска поднимается над кусочками, каждый кусочек проявляет
  аниме-версию со своей задержкой (волна), поверх проходит блик, потом
  открывается окно с ползунком.
* Исходники весят ~26 МБ, поэтому игра грузит webp-копии из `assets/opt`
  (около 3.8 МБ на все 11 кадров) и подгружает их заранее при входе на уровень.
* Победный звук в финале — фраза из «Gran Vals» Франсиско Тарреги (1902,
  общественное достояние): та самая мелодия, которую все знают как рингтон Nokia.
